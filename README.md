## 为什么不是"又一个动画网页"

- **真的在跑算法**：每个动画都是把算法真实执行一遍、逐步记录状态，再按帧播放；不是先画好 Gif 再配音。画面里的比较次数、指针、堆区、D 表都是当场算出来的。
- **正例 + 反例**：18 档错误演示——链表先断后连、把 `>` 写成 `>=`、把 `low<=high` 写成 `low<high`……每一档都必须真的演出可观察的后果，由发布前的自动检查逐档核对，不是只换个红字。
- **为课堂投影设计**：单屏不滚动、教材伪代码随执行高亮、自动播放按解说长度定帧、「第 N 趟/轮」边界多停一拍；放映中按 `C` 直接切换动画，`PageDown`/`PageUp` 按节拍跳转。
- **断网也能用**：一个约 650 KB 的 HTML 文件，双击就开，不装环境、不联网。教室机、U 盘、离线机房都能跑。
- **手机也能看**：≤700px 独立布局，可点元素全部 ≥44px；手机放映只留画面，左右缘 ‹ › 翻页，竖屏进入自动转横屏。
- **分享到某一帧**：60 个单动画页（约 80–120 KB）+ 二维码 + `#m=模块&f=帧号` 深链接。发给学生就停在你要讲的那一步，也可以 iframe 嵌进作业页。

## 它是怎么做到的

<div align="center"><a href="assets/arch.png"><img src="assets/arch.png" alt="帧驱动架构：播放器 → 帧引擎 → 算法逻辑层 / 渲染层" width="100%"></a></div>

- **算法先跑一遍，播放只是移动指针。** 每个动画先把算法真实执行完，逐步记录状态快照；播放、回退、拖动进度条、深链接跳帧都只是移动指针。同一帧永远画出同一画面，回退到第 3 步和第一次播放到第 3 步逐字节相同。
- **一份内容，两种产物。** 全部样式、引擎与 60 个动画内联成一个约 650 KB 的 HTML；另有 60 个约 80–120 KB 的单动画页。没有框架、没有打包器、没有 CDN，不加载外部资源、不发网络请求、不写 cookie/localStorage。
- **每一帧都可寻址。** `#m=模块&f=帧号` 直接定位到课堂那一步；配合 60 个单页、二维码和 iframe，发给学生就停在你要讲的位置。
- **为投影做减法。** 单屏不滚动、伪代码随执行高亮、自动播放按解说长度定节拍、「第 N 趟/轮」边界多停一拍；手机端另有一套 44px 可点元素的布局。

## 质量与验证

正确性不是"看起来对"。每个版本发布前都要过三段自动卡口：**1003 项正确性断言 + 119 项手机视口卡口 + 7 项画布文字实测**，必须保证 1129 项全绿；再加一轮 **63 项全量功能实测**，348 组输入、8,475 帧全部渲染过。

<details>
<summary><b>这些数字查的是什么</b></summary>

- **教材对拍**：排序每一趟结果、KMP 的 next 数组、B 树/B+ 树结构不变式、Dijkstra 的 D 表、Prim/Kruskal 总权值、关键路径工期……逐项对照教材/PPT 例题。
- **错误演示必须真出错**：18 档错法逐档核对"真的演出可观察的后果"，不是换个红字。比如把 `>` 写成 `>=`，序列仍然有序，但稳定性没了。
- **手机与投影**：390×844 / 844×390 无横溢、可点元素 ≥44px、画布文字真实宽度不越出边界、放映态解说 ≤150 字。
- **数字不手写**：断言数、输入组数、帧数由发布脚本从实跑结果回填。

合起来是 **1003 项断言**（外加 119 项手机视口/放映实测 + 7 项画布文字实测）。

## 常见问题

**Q：github.io 打不开 / 很慢？**
国内访问 GitHub Pages 不稳定。下载 zip（[仓库内直链](https://github.com/ch1209498273/ds-animations/raw/main/ds-animations-v3.26.zip)），解压双击打开，体验完全一致。

**Q：手机上能用吗？**
能用，推荐 **⛶ 手机放映**：只留画面，左右缘 ‹ › 箭头翻页，画面严格铺满窗口不用拖动，竖屏进入自动转成横屏，右上角 ✕ 退出，`&mp=1` 深链可分享。
注意画布是 980 单位宽的横宽比，**竖屏下宽度只有 390px，字必然只有 5~7px**——这不是没做适配，是几何决定的，请用横屏或双击放大。

**Q：不是这个教材/学校能用吗？**
可以。界面只对齐《数据结构（C语言版）》通用章节体系（严蔚敏经典八章），不绑定任何学校；两套教材章节编号兼容。站内动画顺序 = 教材小节顺序（v3.0 起）。

**Q：怎么给学生的作业里嵌入某个动画？**
iframe 引用在线地址即可（示例见上面的「复制 iframe 嵌入代码」），目录页可一键复制任意动画的深链接。

**Q：能改成自己的例题吗？**
第 2、3、4、5、7、8 章的多数模块支持自定义数据/表达式/存储结构；第 6 章的图模块目前是预设图，自定义图已排期。需要校本定制或二次开发，联系作者。

**Q：源码开放吗？**
公开仓库只发布可运行的课件成品与配套文档。完整源码不在公开仓库提供，避免被整体搬运、换壳或二次售卖；课堂教学、备课、学生自学都不受影响。需要二次开发、校本定制或商业授权，联系 **1209498273@qq.com**。
