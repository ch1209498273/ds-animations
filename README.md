# 《数据结构》互动课件

16 个可交互的算法动画，覆盖《数据结构（C语言版）》第 2~6 章：
线性表 · 栈和队列 · 树和二叉树 · 图。

**点开 index.html 即用**：不联网、不安装软件，手机/电脑浏览器均可打开。

## 动画清单

| 章节 | 动画 |
|---|---|
| 第2章 线性表 | ① 顺序表插入/删除 ② 单链表插入/删除 |
| 第3章 栈和队列 | ③ 顺序栈 ④ 循环队列（三方案） ⑤ 汉诺塔递归栈 ⑥ 括号匹配 ⑦ 表达式求值 |
| 第5章 树和二叉树 | ⑧ 四种遍历 ⑨ 中序线索二叉树 ⑩ 哈夫曼树与编码 |
| 第6章 图 | ⑪ DFS/BFS ⑫ 最小生成树 ⑬ Dijkstra ⑭ Floyd ⑮ 拓扑排序 ⑯ 关键路径 |

每个动画支持：单步/播放/变速、自定义数据、错误场景演示、一键截图。
