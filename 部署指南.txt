【部署指南】数据结构互动课件 · GitHub Pages

本项目的线上站点部署在 GitHub Pages：
  https://ch1209498273.github.io/ds-animations/
（本地文件夹名 gitee-pages/ 是历史遗留，实际就是 GitHub Pages 的发布目录。）

一、首次部署
  1. 在 GitHub 建仓库（如 ds-animations），把本目录下的全部内容推送上去：
     index.html、a/（43 个单动画分享页）、assets/（图片素材）、
     src/ 与 tests/（源码与测试，供 CI 与二次开发）、build.py、
     LICENSE、README.md、CHANGELOG.md、ds-animations-v2.1.zip
  2. 仓库 Settings → Pages → Source 选 "Deploy from a branch"，
     Branch 选 main / (root) → Save。
  3. 约 1 分钟后访问上面的网址即可。

二、更新流程
  1. 修改 src/ 下的模块后，在互动课件根目录运行：
       python src/build.py        （重新生成 dist 与 a/ 单页）
     然后把更新后的 index.html、a/ 同步到本目录并提交推送。
  2. 推送前建议本地跑一遍测试：
       node tests/test.js
     GitHub Actions 也会在每次推送后自动运行同一套断言。
  3. 推送后 1~2 分钟线上自动更新（浏览器可能有缓存，强刷 Ctrl+F5）。

三、注意事项
  · 需要上传的不只是 index.html：a/ 单页目录与 assets/ 图片都必须包含，
    否则目录里的"二维码 / 复制链接"和 README 图片会失效。
  · 国内访问 github.io 不稳定时，把 ds-animations-v2.1.zip 直接发给学生
    （解压双击即用，体验一致）。
  · 换自己的账号/仓库名时，记得同步修改 README 与单页 og:url 里的域名。
